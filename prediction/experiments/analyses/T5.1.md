## Interpretation

**Tuning does not solve direction, helps point errors only marginally:**
- Direction: No Optuna trial beats persistence MDA 0.6771±0.0474 on paired 5-fold CV. Best tuned A-enet 0.6634 closes the gap from T4.1 A-enet 0.649 (+0.014) but remains −0.0137 below persistence (and −0.078 for best B NRMSE). Per-fold variance is large (std 0.03–0.06); paired folds-positive vs persistence are 0/5 for all B trials, 1/5 for best A (same as T4.1).
- Point errors: B NRMSE-best 0.001056 is **1.7% better than T4.1 B-enet 0.001075** and **6.6% better than persistence 0.00113** — statistically indistinguishable given std ~0.00045. A NRMSE 0.001100 is worse than B NRMSE-best but better than T4.1 A-enet 0.00119 (7.5% improvement).

**Headroom to the 20% NRMSE goal (0.00113→0.00090, need −20%):**
- T4.1 B-enet achieved −5% (0.001075/0.00113 = 0.951).
- T5.1 B NRMSE-best pushes to −6.6% (0.001056/0.00113 = 0.935) — **32% of the 20% gap closed**, leaving **68% of the gap (0.001056→0.00090 = −14.7% more) unclosed**. If the gated B winner (0.001148) is taken as the deployable model (MRA-selected), it is actually *worse* than persistence on point errors (+1.6%) and headroom is negative.
- Using the codified denominator B-enet 0.001075→0.00090 needs −16.3% more; using global-best 0.001056→0.00090 needs −14.7% more. Either way **the 15% remaining headroom cited in the plan is NOT closed by Optuna alone** — it is modest headroom (1–2%) at best on outer CV, and the optimistic outer-CV bias means true nested generalization would be no better.

**Why so little gain:** ElasticNet's sparsity already captured the signal in T4.1's coarse grid (9 alphas × 3 l1_ratios = 27 combos via inner GridSearchCV). Finer loguniform sampling (70 trials) finds a slightly lower alpha for B (0.00126 vs T4.1's 0.0001–0.003 per fold) but the loss surface is flat: NRMSE varies only ±0.00005 across the best dozen trials, MDA varies ±0.02. The T3.3 result that OWN is a point-error lever for full-history CMAs (ratio 0.781 without late starters, 0.954 full-panel) explains the ceiling — more tuning cannot conjure directional signal that isn't there (near-martingale + 40% flats, T2.3).

**Generalization evidence:** Best hyperparams generalize modestly: B NRMSE-best chosen by minimizing NRMSE still has MDA 0.598 (same as T4.1 B-enet) — no overfit to MDA; A gated-best 0.663 is the highest MDA seen in any T1–T5 run, but its NRMSE 0.001100 is gate-eligible and its per-fold MDA std 0.046 is larger than B's 0.028–0.033, indicating higher variance. No trial shows >2/5 folds beating persistence directionally in paired intersection scoring (spot-checked; all ≤1/5).

## Pitfalls encountered

- **Sentinel and key bugs (T4.4 fixes):** `per_fold_variance.json` previously had zero T4.1 paired fields; fix verified `paired_folds_positive_vs_persistence` present for all 6 T4.1 combos (A/B/C × ridge/enet). Shortlist sentinel `"none"` removed.
- **Pruned B definition mismatch:** T4.1 B used 8 OWN cols, T5.1 B uses 4-col subset — comparable but not identical; direct B-enet vs T5.1 B NRMSE comparison is 8-col 0.001075 vs 4-col 0.001056 (−1.7%) so subset alone is not worse.
- **Outer CV optimism:** Optuna objective minimized outer NRMSE, so reported outer metrics for best trials are optimistic upper bounds; a proper nested inner CV would likely shave 0.5–1% off the gain. We document outer explicitly with caveat.
- **Gate scope:** Global-best after T5 is 0.001056 (B-014) so gate 0.001162 is slightly *lower* than the codified T4 gate 0.001182 — same eligible set but tighter by 1.7%; A-enet's T4.1 0.00119 would be even *more* ineligible under the new gate (1.13×).
