   - `temporal_features.build_own_block`: own `d1`, `d12`, `dlog1` (the draft shifted these GLOBALLY across CMA boundaries);

   All five T3.2 results JSONs + paired tables + plot regenerated; corrected rows appended (latest-timestamp-wins). T3.1 k3/k5 CV + paired rows re-appended too.
2. **[major] `_fill_causal` cross-sectional fill FIXED** — the same-month cross-sectional median (which used OTHER CMAs' contemporaneous feature values and could fire inside validation windows) was replaced by a strictly causal hierarchy: per-CMA ffill → per-CMA strictly-past expanding median → panel expanding median over STRICTLY EARLIER calendar months → counted per-CMA cold-start backfill (fires only when whole cohorts start simultaneously, e.g. 1981–83 warm-up rows) → zero last resort (never fired). Fill incidence quantified below.
3. **SCSS/RMS/Census publication-lag caveat** added to KNOWLEDGE.md standing decisions: covariate t−1 is used as-if-available at t; SCSS/RMS publish with delay and Census is annual — real-time predictability claims must carry this through T6/T8.

5. **Prediction-variance-ratio diagnostic run** (artifacts/T3.3/pred_variance_ratio.json): pooled var(pred_OWN)/var(pred_lag1) = 0.975, corr 0.996, std/truth 0.993 vs 1.005 — a MILD shrinkage effect, not a dramatic one. The shrinkage story is now empirical but modest: per-fold RMSE ratios (0.76/0.84/0.76/0.72/1.87) show folds 1–4 gain from slightly-damped predictions while fold 5 blows up (see #2b below).
6. **KNOWLEDGE.md [T3.2] rephrased**: "T6 forward selection should screen ONLY own-index long-horizon memory" is now pending-researcher-decision phrasing, with the symmetric special-pleading concern flagged (the standing decision bars directional-edge-alone wins while the recommendation admits point-error-edge-alone candidates); both edges need an explicit codified rule before T6.

## 4. HARD GATE: train-only re-imputation sensitivity

`t33_trainonly_imputation.py` rebuilds the pre-split panel byte-identically from the upstream module source (executed up to, but excluding, the joint imputation call — no test-split code path executes), re-runs the IDENTICAL imputation estimators fitted on TRAIN ROWS ONLY (9627 of 12049 pre-split rows), and exports an alternative panel (`artifacts/T3.3/X_train_trainonly_total.csv.gz`, gzipped under the 10MB artifact cap; 7792×176, ids align EXACTLY with the canonical split; 147/176 columns change ≥1 cell, worst column 6.0% of cells — mostly RMS/SCSS annual-series backfills near series starts). The prediction/ CSVs were untouched (test-file sha256 verified unchanged before/after).

**Downstream decision: KEEP the joint-imputation panels as canonical for T4–T7**, because (a) the optimism is negligible for the reference vehicles (|ΔNRMSE| ≤ 0.8% relative, |ΔMDA| ≤ 0.001 — far inside fold-to-fold std ~0.04–0.05), (b) every existing reference row (persistence bar, T2/T3 leaderboards) is on the joint panel and comparability would otherwise be lost, and (c) the alternative panel is committed under artifacts/T3.3/ so any suspicious T4+ result can be re-checked against it cheaply. The caveat ("CV absolutes may be optimistic by ≤~1% relative on point metrics") carries into T6/T8 documentation. The final T8 test evaluation reads the untouched test files regardless, so this decision does not affect the single test-shot protocol.

## Pitfalls encountered

- The first trainonly persistence run accidentally used the frozen-last-value smoke predictor (NaN MDA); caught immediately by the exact-reproduction sanity check and re-run with true one-step persistence (its draft registry row is superseded latest-timestamp-wins).
- The new causal-fill hierarchy initially hit the 0.0-fallback for entire cold-start cohorts (18 CMAs all starting 1981-01 → no earlier data anywhere); resolved with the counted own-CMA cold-start backfill (upstream ffill/bfill convention), which fires ONLY on deep-train warm-up rows (zero in every validation window for full-history CMAs).
- Fixing the temporal builders changed headline T3.2 conclusions (OWN NRMSE ratio 0.778→0.954 full-panel); the original claims remain in history via append-only registry rows, superseded by the corrected rows appended here.
