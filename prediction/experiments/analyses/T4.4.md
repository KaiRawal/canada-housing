## Pitfalls encountered

- **Dedupe & differing-ID trap**: `runs.jsonl` is append-only; `T4.2-rf-A` (lowercase, 1×) vs `T4.2-RF-A` (4×, latest 2026-08-28T04:15:10 is authoritative) must be handled by latest `(run_id,timestamp)` and logical-experiment check (KNOWLEDGE.md trap (a)); also `T4.1-B-enet-niter-proof` and `T4.1-criticfix-evidence` are proof rows, not leaderboard candidates — excluded.
- **Denominator trap**: fold5 `n_val_rows=323` (wide panel) vs `n_eval_rows=317` (direct/recursive common-mask) vs `245` (classical CMA-excluded) — leaderboard and T4.3 table now carry all three and baseline splits; failing to split inflates SARIMAX's apparent closeness to persistence.
- **Codified vs actual-min gate**: difference is 0.2% but documentation must state both (C-enet is actual min, B-enet is codified global-best) — same eligible set so no ranking change, but adjudication of A-enet's 1.106× vs 1.109× vs 1.052× must be explicit.
