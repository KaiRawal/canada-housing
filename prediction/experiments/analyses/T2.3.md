## Part A — critic fixes folded in first

### A.1 Canonical MDA-protocol correction (fix #2) — READ THIS FIRST

`harness._anchored_mda` previously scored a predicted direction of exactly 0
(pred_t == pred_{t−1}) as an automatic miss unless truth was also flat. At the
train→val boundary anchor this systematically handicapped persistence-style
predictors (their first predicted direction is forced to 0). The new canonical
scorer is **`harness.mda_zero_drop`**: directions where EITHER side's signed
change is exactly 0 are dropped, and the SAME rule is applied to model and
baseline blocks (symmetric zero-drop); per-fold scored-direction and
dropped-direction counts are logged for auditability. `evaluation.py` itself
is untouched (it still serves the upstream pipeline).

**Why the numbers move more than expected:** the NHPI `total` series has long
flat runs — of 2039 candidate directions pooled across the 5 folds,
853 have a zero PREDICTED change, 805 a zero TRUE change (406 overlap).
Roughly 40% of month-over-month moves are exactly 0 (index granularity +
upstream interpolation). Under the old rule every "moved-then-flat" or
"flat-then-moved" month was an automatic miss for whoever predicted nonzero.

**NEW CANONICAL PERSISTENCE REFERENCE (5 expanding folds):**

| | MDA | NMSE | NRMSE | NMAE |
|---|---|---|---|---|
| persistence (old protocol) | 0.4625 ± 0.0394 | 1.52e-06 ± 1.27e-06 | 0.00113 ± 0.00049 | 0.00061 ± 0.00024 |
| **persistence (zero-drop)** | **0.6771 ± 0.0474** | 1.52e-06 ± 1.27e-06 *(unchanged)* | 0.00113 ± 0.00049 *(unchanged)* | 0.00061 ± 0.00024 *(unchanged)* |

Point metrics are bit-identical pre/post fix — ONLY MDA moved. Sensitivity:
under the narrower alternative rule ("drop ONLY predicted zeros", true-flat
months kept as misses) persistence scores 0.4501±0.0493 — close to legacy;
the adopted symmetric either-side rule is the fairest paired protocol because
no predictor is credited or penalised for months in which the index did not
move at all. Old-rule numbers remain preserved in their original runs.jsonl
rows; corrected rows are appended (append-only).

### A.3 Direct-sign diagnostic for Δlog / YoY heads (fix #1)

Scored sign(raw Δlog pred) and sign(YoY-implied monthly change) == sign(YoY
pred) DIRECTLY against sign(Δy_true) on the identical common-mask rows as the
level-space scoring (registry rows `T2.2-directsign-dlog/-yoy`; artifact
`direct_sign_diagnostic.json`). Reference = momentum sign(y_{t−1} − y_{t−2})
(persistence's implied direction) on the same rows, symmetric zero-drop:

| Raw head | direct-sign accuracy | momentum reference |
|---|---|---|
| Δlog pred | 0.6076 ± 0.0848 | 0.6782 ± 0.0493 |
| YoY% pred | 0.5808 ± 0.0839 | 0.6772 ± 0.0479 |

Interpretation: the transformed-target heads DO carry genuine above-chance
directional signal (0.58–0.61 ≫ 0.50 coin) — the earlier "REFUTED" wording was

momentum, and weaker than what the same ridge achieves predicting the level

beating persistence; no decision changes.

## Part B — the LOCO probe

### Decision rule (stated up front)

Spatial pooling is deemed **PROMISING** iff pooled-LOCO beats BOTH (a)
persistence and (b) a self-fit ridge trained on the held-out CMA's OWN train
history on >50% of evaluable held-out CMAs (per-CMA aggregate MDA over the 5
canonical folds) without a hopeless NRMSE class. Otherwise → temporal-only
path for T3/T4.

### Design

Vehicle = the T2.1 pooled Ridge(α=1)-on-lags + CMA dummies, reused verbatim
(`baselines_suite.ridge_lags_model_fn`, StandardScaler fitted inside the fold's
train window). Per (fold, held-out CMA) cell:

- **LOCO pooled:** fit excludes ALL train-window rows of the held-out CMA; its
  dummy is unseen → handled by the existing `reindex(fill=0)` (predicted from
  numeric lags alone). 96 cells (18 CMAs × folds 1–4 + 24 CMAs × fold 5).
- **Self-fit:** same function fitted on ONLY that CMA's train rows; requires
  ≥24 monthly train rows. Exclusions: the six ~2016-12 late starters have ZERO
  train rows in every canonical fold → excluded and counted (never fudged);
  Charlottetown (~1995) qualifies everywhere.
- Scoring via `harness._score_fold` on exactly the held-out CMA's val rows;
  persistence paired on identical masks; boundary anchor uses the CMA's last
  TRAIN observation (past info only). All fits see train-window data only.

Compute: ≤120 pooled + ≤120 self fits, trivial.

### VERDICT: spatial pooling does NOT help → temporal-only path

The pre-stated decision rule fails decisively. Cross-CMA transfer of a pooled
lag-regression is WORSE than each CMA's own information on direction
(vs persistence: mean ΔMDA −0.087) AND materially worse on levels
(NRMSE 0.054 vs 0.019, 2.8×). Self-fitting is even worse on levels
(NRMSE 0.0995) — small-history ridge without cross-CMA sharing overfits local
scale (e.g. Vancouver 0.53, Saskatoon 0.24) — confirming pooling helps LEVELS
relative to self-fit (+0.019 mean ΔMDA, halved NRMSE) while still losing to
persistence everywhere that matters.

**Recommendation for T3: do NOT invest in kNN spatial-lag / region / centroid
features as a primary direction-fixing lever (T3.1 deprioritised to a cheap
ablation slot at most); prioritise T3.2 temporal features.** Caveat kept
explicit: LOCO tests out-of-CMA generalisation of pooled LAG models, which is
necessary-but-not-sufficient evidence against spatial-lag FEATURES (neighbour
lags could still add incremental value to a within-CMA model); any T3.1 work
should be justified as ablation, not as a bet.

## Pitfalls encountered

- Cell heterogeneity: folds 1–4 contain only 18 CMAs (late starters absent),
  and the six ~2016-12 starters contribute single-fold cells with as few as
  one scored direction (their MDA values are anecdotal and flagged "-" where
  undefined — e.g. Trois-Rivières' persistence had zero non-flat directions).
  Verdict counting therefore uses only the 18 full-coverage CMAs.
- First probe run crashed on a pandas merge column collision
  (`n_folds_evaluated_x/_y`) and a missing `json` import — fixed; re-runs used
  `--no-log` to avoid duplicate runs.jsonl rows (append-only policy).
- Self-fit ridge on short histories produces wild level extrapolation
  (NRMSE up to 0.53) — documented as a finding (pooling stabilises levels),
  not fudged away.
- The corrections sweep initially asserted equal direction-set sizes between
  raw-signal and momentum-reference accuracies; each side legitimately drops
  its own zero directions, so both counts are recorded instead.
